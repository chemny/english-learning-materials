## 单页验收

逐项检查，不凭缩略图判断：

- [ ] 标题、教材、单元和册次正确。
- [ ] 标题区和单元主题区各项只在确认区域出现一次；拆分标题没有在模块标签、词汇栏或装饰中再次拼接出现。
- [ ] 英文逐字拼写正确，大小写和标点正确。
- [ ] 中文逐字正确，无乱码或错别字。
- [ ] 每个单词与中文释义一一对应。
- [ ] 每个配图与对应词义或动作匹配。
- [ ] `drink/thirsty`、`healthy/delicious`、`favourite/dear` 等易混词使用了不同的动作或状态证据。
- [ ] 每张词卡只有一个编号；英文词汇前没有再次添加同一数字。
- [ ] 句型完整，没有漏词、改写或重复。
- [ ] 知识提示区逐项显示中文学习功能和英文核心句式；没有出现 `Make requests`、`Ask about preferences`、`Describe food` 等元语言标签翻译。
- [ ] 同一功能的多条英文核心句式按确认卡分行显示；图片中没有出现字面量 `<br>` 或用斜杠挤成一行。
- [ ] 图片中没有白名单外文字、水印或商标。
- [ ] 装饰书本、黑板、笔记本和文具没有自行出现科目名、标签或口号；知识提示中的加号、箭头和分隔符没有被图标替换。
- [ ] 字号可读，文字没有被边缘、人物或装饰遮挡。
- [ ] 人物、物体、建筑、图标、圆形编号和文字保持自然宽高比，没有拉长、压扁、横向扩展或纵向压缩。
- [ ] 背景白平衡符合所选主题，没有全页黄色覆盖层、棕褐色滤镜、旧纸张或异常棕色阴影；黄色只作局部强调。
- [ ] 标题层级、视觉锚点和区域平衡符合所选主题；精确比例已根据内容负载调整，没有机械套用或无意义留白。
- [ ] 现代学习手账头部保持开放冷白方格纸，不存在包住整组标题的巨大深蓝面板、整列深蓝卡片或企业看板式色块。
- [ ] 核心词汇区的列数、外框数量和内部线型符合所选主题，不混用其他主题的边框拓扑。
- [ ] 底部句型区、提示区、人物或物件锚点和页脚符合所选主题，不是通用白色文本框。
- [ ] 图片尺寸、比例和方向符合清单。
- [ ] 对照所选风格协议完成 `S01` 检查，媒介、主色、标题结构、内容结构和复习区均匹配。
- [ ] 人物看起来属于目标年龄段，没有明显幼儿化或成人化。
- [ ] 小学高年级、初中或高中人物没有婴儿脸、幼儿头身比、超大头、超大眼、短肢体、Q版身体、幼儿园道具或明显低于目标年龄的角色造型；出现任一明显低龄化特征即记录 `A01`，不得因提示词写有年龄数字而放行。
- [ ] 人物比例、眼睛大小、服装、姿态、动作和场景共同支持目标年龄判断，不依赖单一脸型或刻板身体特征。
- [ ] 场景、物件、色彩装饰和信息密度符合目标年龄段。
- [ ] 同一张图和同一批次的人物媒介一致，没有照片感、三维渲染人物与二维手绘插图混搭。
- [ ] 图片中的标题、词汇、句型、知识提示、分区状态和页数与最终成品内容确认卡一致。
- [ ] 主体模块数量和名称与 `EXACT MODULES` 完全一致；没有语音、语法总结、练习、学习目标等额外板块。

使用当前运行时的原生视觉能力打开原始分辨率图片，不依赖缩略图判断。按以下顺序逐区对照唯一可见文字白名单：

1. 标题区：教材、年级册次、单元和中英文主题。
2. 词汇区：编号、英文词汇、中文释义、配图语义和白名单外说明。
3. 句型区：逐句核对拼写、标点、数字粘连、漏词和重复。
4. 知识提示区：中文功能与英文核心句式对应、换行、分隔符和完整性。
5. 全图复查：水印、装饰文字、重复编号、拉伸压扁和遮挡。

只有逐区核对完成且没有未解决差异，才能把“文字检查”标记为通过。视觉判断不确定时，放大对应区域或重新生成当前图片，不通过额外文字识别工具替代判断。

## 失败处理

记录错误类别和实际内容：

| 代码 | 含义 | 处理 |
|---|---|---|
| T01 | 英文拼写或标点错误 | 强化逐字文本并重试当前页 |
| T02 | 中文乱码或错字 | 缩短页面文字或拆页后重新确认 |
| T03 | 词义或配图错配 | 明确逐项映射并重试当前页 |
| T04 | 出现白名单外文字或配图说明被印出 | 把配图语义标为不可见视觉指令，明确词卡只显示编号、英文和中文，并重试当前页 |
| T05 | 词卡重复编号 | 只保留一个圆形编号徽章，删除英文词汇前的数字前缀并重试当前页 |
| T06 | 知识提示缺少中文功能或英文核心句式 | 补齐逐项句式、更新白名单并重新确认；用户明确选择仅中文时例外 |
| T07 | 知识提示误用英文标签直译 | 删除 `Make requests` 等元语言翻译，改用当前单元可直接套用的核心句式并重新确认 |
| T08 | 标题、单元主题或其拼接别名重复出现 | 以成品分区确认生成区域化文字计划，移除拼接别名；生成包仍含冲突时不得调用图片工具 |
| P01 | 白名单文字没有确定的确认区域或学习内容位置 | 补充分区归属或从白名单移除；完成重新确认前不得生成 |
| L01 | 信息拥挤或遮挡 | 调整结构；若拆页则回到内容确认 |
| L02 | 明显超载且尚未选择有效处理方式 | 选择自动适配、拆页或经用户确认后单页尝试 |
| L03 | 用户确认在启发式超载状态下单页尝试 | 加强字号、遮挡、漏字和层级验收；失败后优先拆页 |
| M01 | 历史知识提示模式试图重新确认或生图 | 升级为“中文功能＋英文核心句式”，更新白名单并重新确认 |
| M03 | 清单版本 1–3 试图重新确认或生图 | 迁移到清单版本 4，补齐候选池、固定数量和模块锁后重新确认 |
| D03 | 主体模块、禁止模块或分区不精确 | 恢复对应模式的精确模块白名单，删除未知模块并重新确认 |
| D04 | 词汇档位或网格不确定 | 按候选数和版式上限重算 25/20/16/12/9 档位 |
| D05 | 候选池与学习内容不一致 | 以确定性入选结果重建学习内容和白名单 |
| D06 | 句型或知识提示数量缺失 | 继续检索到至少 2 组；最多固定选 4 组，不得省略模块 |
| B01 | 批量缺页或重复 | 只补生成缺失任务，不重做通过项 |
| A01 | 人物或画面年龄不匹配，包括高年级人物幼儿化、Q版化或参考图造成低龄迁移 | 保留当前版式和媒介，强化年龄锁定中的人物比例、眼睛、服装、姿态、场景与低龄负面约束后重试当前页 |
| S01 | 风格不匹配 | 对照风格协议补强缺失的媒介、色彩、结构或负面约束后重试当前页 |
| S02 | 图片、人物、图标或文字比例变形 | 强化自然宽高比、4:3 contain安全框、正常字宽和禁止非等比缩放后重试当前页 |
| S03 | 头部比例导致层级失衡、空洞或挤压正文 | 以主题推荐比例为起点重新平衡标题、视觉锚点和正文空间 |
| S04 | 内容区边框拓扑错误 | 按主题恢复外框数量、卡片边框和内部线型，删除嵌套框或跨主题边框 |
| S05 | 头部构图不足 | 从主题推荐的人物、静物、徽章、标签或几何元素中选择必要锚点，消除空洞但不堆砌道具 |
| S06 | 底部风格不匹配 | 恢复该主题的句型栏、提示卡、人物或桌面物件以及专属页脚结构 |
| S07 | 参考图版式偏离 | 对照参考图重新锁定头部、网格列数、底部比例和锚点位置后重试 |
| S08 | 文字DNA退化 | 补全该主题的无图版式蓝图，禁止生成通用工作表、白底卡片或其他主题结构 |
| S09 | 背景泛黄或出现旧纸滤镜 | 恢复主题规定的中性浅色背景，限制黄色为局部强调，禁止黄色覆盖层、棕褐滤镜和棕色阴影 |
| S10 | 手账头部出现巨大深蓝色块或企业看板结构 | 恢复开放冷白方格纸，让大标题直接落在白底，仅保留小型深蓝或薄荷页签，并把深蓝实色面积限制在头部约18%以内 |
| C01 | 教材身份或单元标题不完整 | 返回教材核验，不进入生图 |
| C02 | 词汇缺少具体配图语义 | 补充可画对象或动作并重新确认 |
| C03 | 资料类型缺少必需内容 | 继续检索、请求教材页或经用户同意缩小资料范围 |
| C04 | 成品分区与确认内容不一致 | 修正清单并重新通过确认门 B |
| V01 | 版本策略、检索日期或核验状态无效 | 重新检索当前适用版本，不进入确认门 B |
| V02 | 来源不能证明版本或适用学年 | 补充官方目录、出版社新版说明或正式选用依据 |

同一页最多进行两次有针对性的纯生图重试。仍不合格时如实报告，并让用户选择继续纯生图、减少信息量或启用可选文字准确模式；不得静默切换。
