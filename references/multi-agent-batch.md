# 多子 Agent 批量生图

只并行已经通过两个确认门、内容彼此独立的图片任务。教材检索、版本核验、内容确认、公共提示词冻结和最终验收始终由主 Agent 负责。

## 适用条件

- 至少2张独立图片，例如多个单元、多个主题或参考图版与文字视觉 DNA 版。
- 当前运行时支持子 Agent；不支持时按同一任务表顺序执行，不阻断交付。
- 所有任务已有独立文件名和输出目录，不会覆盖同一文件。

## 主 Agent 职责

1. 冻结教材身份、清单版本、每个单元各自的唯一可见文字白名单、年龄段、配图语义表和公共负面约束。
2. 对每张已确认清单运行 `build_generation_package.py`，建立带内容指纹的只读 `generation-package.md`：任务编号、主题协议、参考图角色、目标尺寸、输出文件名、三段提示和验收重点都由主 Agent 冻结。
3. 按运行时并发上限分组派发；主 Agent 占用并发槽时通常同时运行3个子 Agent，运行时允许更多时最多使用4个，不超过工具或账号允许的上限。
4. 汇总子 Agent 返回的图片路径、实际提示词、错误和重试次数。
5. 统一复制到任务目录，运行尺寸校验、文字检查、视觉检查和整组一致性检查。
6. 只重新派发失败图片，不重做已通过图片。

## 子 Agent 边界

- 每个子 Agent 一次只负责一张图或一个明确页面。
- 只读取主 Agent 构建的 `generation-package.md` 和其中登记的参考图；不重新拼装提示词。
- 不重新联网搜索教材，不改变版本、词汇、翻译、句型、知识提示、年龄或页数。
- 不修改公共清单、批量索引、技能协议或其他子任务文件。
- 生成结果使用唯一临时文件名；返回路径后由主 Agent 决定是否进入最终目录。
- 发现内容无法容纳或来源有问题时报告主 Agent，不自行删词、拆页或改写。

## 推荐拆分

- 多单元同主题：每个单元一个子 Agent。
- 同一内容多主题：每个主题一个子 Agent。
- 同一主题双通道：参考图增强版和文字视觉 DNA 版可分给两个子 Agent。
- 超过并发上限：按3–4张一组分波次执行。

## 一致性保护

- 多单元任务的每个单元保留自己的白名单和配图语义表，不得跨单元混用；同一单元的多主题或双通道共享该单元已确认内容。
- 尺寸、年龄协议和公共负面约束可在同批次共享，但每张图仍使用独立只读任务包、文件名和验收记录。
- 公共提示词块由主 Agent 构建，子 Agent 只能追加本主题固定提示块和任务映射。
- 同一词的核心配图对象不变，只允许画风、颜色和局部构图变化。
- 主 Agent 最终检查主题内双通道结构、整批文件数量和命名。

并行能缩短等待时间，但不能消除图片生成服务的并发限制、排队时间或随机性。若服务限流，降低并发并按任务表继续，不改变内容。
