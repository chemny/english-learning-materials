# 年龄适配规范

年龄适配不仅控制人物外观，还同时控制场景、插图成熟度、色彩、装饰、字体和单页信息密度。

## 判定顺序

1. 用户明确提供实际年龄或学习者阶段时，使用用户指定值。
2. 用户只提供年级时，按下表自动推断。
3. 年级无法识别、教材跨年龄使用或学习者与教材年级不一致时，在确认门 B 前请用户确认。
4. 同一批次默认锁定同一年龄段；只有目标学习者确实不同时才逐页调整。

## 年级映射

| 教材或学习阶段 | 学习者年龄段 |
|---|---|
| 学前、幼儿 | 学前（4–6岁） |
| 小学一至二年级 | 小学低年级（6–8岁） |
| 小学三至四年级 | 小学中年级（8–10岁） |
| 小学五至六年级 | 小学高年级（10–12岁） |
| 初中、七至九年级、初一至初三 | 初中（12–15岁） |
| 高中、高一至高三 | 高中（15–18岁） |
| 大学、职业学习、成人学习 | 成人（18岁以上） |

年龄范围用于视觉设计，不用于判断个体发育情况。

## 视觉调整

| 年龄段 | 人物与场景 | 色彩与装饰 | 字体与信息密度 |
|---|---|---|---|
| 学前 | 幼儿形象、家庭或游戏场景、大而直观的单物件插图 | 明亮高饱和、圆形和贴纸元素较多 | 超大字号、极少文字、单页少量内容 |
| 小学低年级 | 6–8岁儿童、课堂和生活动作、图像直接解释词义 | 活泼明亮、卡通装饰较多 | 大字号、短句、低密度卡片 |
| 小学中年级 | 8–10岁儿童、课堂家庭与主题场景、动作关系清楚 | 童趣但层级更规整、装饰适中 | 中大字号、词汇与基础句型并列 |
| 小学高年级 | 10–12岁学生、较成熟的校园和生活场景、插图更简洁 | 降低幼儿化装饰，配色清爽 | 中等字号、结构化复习、信息密度适中 |
| 初中 | 青少年形象、真实但友好的学习与社会场景 | 低饱和或清晰主题色，少用幼儿贴纸 | 清楚层级、可容纳语法与阅读要点 |
| 高中 | 高中生形象、学术或现实语境、图形辅助为主 | 克制成熟、装饰最少 | 较高信息密度，强调逻辑和重点 |
| 成人 | 成人形象或无需人物的专业场景 | 简洁专业，按使用场景选色 | 高效扫描、术语和情境表达优先 |

## 提示词要求

在生图提示中明确写入：

- `Learner age band`：清单中的学习者年龄段。
- `Character age and visual maturity`：人物应看起来属于该年龄段，不幼儿化或成人化。
- `Scene and object maturity`：场景与物件符合该阶段的生活和学习经验。
- `Color and decoration maturity`：色彩饱和度与装饰数量符合该阶段。
- `Typography and information density`：字号、行长和单页内容量符合该阶段。

即使画面不出现人物，也必须适配插图复杂度、装饰成熟度和信息密度。

### 年龄硬约束

- 年龄视觉层只调整人物、场景、道具、装饰成熟度、字体成熟度和信息密度，不得替换用户已经确认的版式、媒介、主色、标题层级或边框结构。
- 手绘、卡通、漫画、校园杂志和学习手账都是媒介或版式选择，不绑定特定年龄。相同版式必须能够叠加不同年龄视觉层。
- 小学高年级及以上的人物不得呈现为幼儿或小学低年级形象。禁止用婴儿脸、幼儿头身比、超大头、超大眼、短肢体、Q版身体、幼儿园道具或贴纸堆叠表现高年级学习者。
- 初中人物必须具有自然青少年比例、正常大小眼睛、较长四肢、符合年龄的姿态、服装和校园兴趣场景；不得只写年龄数字而继续沿用小学低龄角色造型。
- 高中人物必须呈现为较成熟的青少年，不得幼儿化，也不得画成职场成年人；人物不必要时优先使用符合年龄的信息图、学习物件或局部动作。
- 参考图与目标年龄冲突时，只继承其版式、媒介、配色、层级和装饰节奏；人物年龄、身体比例、服装、场景和年龄化装饰必须由目标年龄层覆盖。
- 生图任务包必须包含独立年龄锁定块，并明确它只覆盖冲突的年龄线索，不改变用户选择的版式和媒介。

## 安全边界

- 未成年人只使用自然、日常、非性化的衣着、动作和场景。
- 不通过身体特征夸张年龄，不把低年级角色画成幼儿，也不把高年级角色画成成人。
- 不用刻板的性别、职业、地域或族群特征表示年龄。
- 人物年龄无法稳定生成时，优先使用中性学习角色、局部动作或物件插图，并保持整体年龄适配。
