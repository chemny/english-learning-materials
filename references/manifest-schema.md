# `material-manifest.md` 规范

每张图片使用一份独立清单。批量任务不得让多个单元共享候选池、入选内容或可见文字白名单。新任务统一使用 `清单版本：4`；版本 1–3 的历史交付记录可读，但重新确认或生图前必须迁移并重新通过确认门 B。

## 创建标准模板

不要手抄模板。使用初始化脚本生成两种受支持模式之一：

```bash
python scripts/init_material_job.py --output <任务目录> --slug <任务名> --units <单元...> --material-type 词汇复习海报
python scripts/init_material_job.py --output <任务目录> --slug <任务名> --units <单元...> --material-type 单元复习海报
```

脚本写入当前 `Skill版本`、`内容契约版本`、固定主体模块、候选池、六个版式责任区和参考图相对路径。不得删除这些字段或另造第三种模式。

## 版本 4 必填结构

### 任务信息

除教材、版本、年龄、标题、风格和确认状态外，必须包含：

- `Skill版本：1.2.0`
- `内容契约版本：exact-modules-v1`
- `资料类型`：只允许 `词汇复习海报` 或 `单元复习海报`
- `主体模块`：词汇模式为 `核心词汇`；单元模式为 `核心词汇 + 核心句型 + 知识提示`
- `额外学习模块：禁止`
- `词汇数量档位`：25、20、16、12、9 之一
- `词汇网格`：与档位严格对应的 5×5、5×4、4×4、4×3、3×3
- `句型组数`：词汇模式固定 0；单元模式为 2–4
- `知识提示组数`：词汇模式固定 0；单元模式为 2–4

用户未指定版次时，`版本策略` 必须为 `当前最新适用版本`。`版本检索日期` 使用当天 `YYYY-MM-DD`，超过 30 天必须重新核验；来源证据至少一条支持版本、适用学年或新版状态。

### 候选池

`词汇候选池` 保存教材顺序、英文、中文、内容类型、重要性等级、是否入选、选择说明和来源位置。重要性等级 1 最高、5 最低；词汇按 `重要性等级 → 教材顺序 → 英文词形` 升序排序，选择版式上限内的最大允许档位。

`句型候选池` 和 `知识提示候选池` 保存教材顺序、双语内容、是否入选、场景和来源。单元模式各选 2–4 组；候选达到 4 组时固定选前 4 组。词汇模式保留空表，不加入占位内容。

`是否入选` 只允许 `是` 或 `否`。候选池、`学习内容` 和任务信息中的数量必须三方完全一致；未入选内容不得进入白名单或任务包。

### 学习内容

只记录已入选内容，使用九列结构：编号、成品区域、内容类型、英文可见文字、中文可见文字、音标或词性、配图或呈现方式、使用场景或说明、来源位置。

- 词汇行必须有具体可画对象或动作。
- 词汇模式不得出现句型或知识提示行。
- 单元模式不得出现词汇、短语、句型、知识提示以外的类型；`语法` 不再作为独立内容类型。
- 一个问答对计为一个句型组。
- 一个中文学习功能及其 1–2 条英文句式计为一个知识提示组。
- 知识提示英文必须是可套用核心句式，不得使用 `Make requests`、`Ask about preferences`、`Describe food` 等元语言标签翻译。
- `<br>` 只表示不可见换行；两侧文字分别进入白名单，图片中不得显示 `<br>`。

### 主体模块锁定

词汇模式必须精确锁定一行 `核心词汇 / 必须展示`；单元模式必须按顺序精确锁定：核心词汇、核心句型、知识提示。

`禁止模块` 必须完整列出契约中的所有禁止项。标题、教材与单元信息是头部；人物、插图、图标和装饰是视觉元素；二者都不计入主体模块。

### 成品分区确认

六个责任区必须且只能是：标题区、单元主题区、核心词汇区、核心句型区、知识提示区、视觉信息区。未知分区直接校验失败。

- 词汇模式：核心句型区和知识提示区必须为 `不展示`，其余责任区为 `展示`。
- 单元模式：六个责任区均为 `展示`。

责任区用于验收，不要求六个独立视觉框；相关内容可共享容器，但不得产生额外学习模块。改变页数、主体模块、入选内容或白名单后，必须重新确认。

### 唯一可见文字白名单

逐条穷举标题、标签和所有已入选学习内容。配图语义、动作说明、来源、风格词、路径和文件名属于不可见指令，不得进入白名单。任何白名单外可见文字都属于失败。

白名单只定义允许边界，不直接等于必须逐条渲染的提示词。任务包编译器必须根据 `成品分区确认`、主体模块锁定和 `学习内容` 生成“区域—文字—次数”计划。标题拆分形式与其拼接别名同时存在时，以成品分区确认中的拆分形式为准，拼接别名必须从整个任务包移除；无法归入标题、单元主题、显式模块标签或学习内容的其他白名单项以 `P01` 阻断生成。若确需页脚或其他可见文字，应先把它纳入可验收的确认区域，不得仅追加到白名单。

## 确定性容量

| 版式 | 词汇上限 | 允许档位 |
|---|---:|---|
| compact-grid | 25 | 25/20/16/12/9 |
| standard-grid | 20 | 20/16/12/9 |
| large-card-grid | 12 | 12/9 |
| custom | 20 | 20/16/12/9 |

候选不足 9 个时，不得生造内容或随机降到任意数量；继续检索、请求教材页或报告阻塞。容量检查只能在固定档位之间降级，不得使用 10、13、18 等任意数量。

## 校验与任务包

确认门 B 前运行：

```bash
python scripts/check_layout_capacity.py <material-manifest.md>
python scripts/validate_manifest.py <material-manifest.md> --stage confirm
python scripts/render_confirmation_card.py <material-manifest.md>
```

用户确认后把 `内容确认` 改为 `已确认`，再运行：

```bash
python scripts/validate_manifest.py <material-manifest.md> --stage generate
python scripts/build_generation_package.py <material-manifest.md>
```

生成的任务包必须同时包含：内容指纹、参考资产指纹、`EXACT MODULES`、`FORBIDDEN MODULES`、区域化可见文字计划、语义别名零次锁、内容到配图映射和执行锁。不同电脑只有在 Skill 版本、清单、任务包和参考资产指纹一致时，才算使用同一输入。

## 批量任务

每个单元拥有独立清单和任务包；同一单元生成多个主题时，可派生多个只读风格任务包，但白名单、主体模块和数量不变。批量执行方式可以并行或顺序回退，不能改变内容契约。
