# 教材检索与来源规则

## 目标

确认指定教材、版本、年级册次和单元，建立可回查的内容依据。搜索的产物是来源证据和教材确认卡，不是未经确认的最终教材内容。

## 版本时效原则

- 用户未指定年份或版次时，默认检索“截至当前日期，已正式发布或已进入适用学年、且适用于目标年级册次的最新版本”。不要因为旧版资料更多、更容易访问而默认旧版。
- “最新”必须同时匹配出版社、起始年级、目标年级、册次和适用学年；不能用其他起点、其他地区或尚未投入目标年级使用的版本替代。
- 优先检查当前或下一适用学年的官方教材目录、出版社新版教材说明、国家智慧教育平台和地方教育主管部门正式选用公告。
- 新旧教材并行或新版分年级启用时，分别记录“最新已发布版本”和“用户所在地当前采用版本”。所在地会改变结论时，再询问用户所在省市或学校实际用书。
- 旧版页面、旧教案和历史词表只能用于版本对比，不能单独证明当前版本内容。
- 每次新任务都重新核验版本，并在清单中记录检索日期、版本策略、最新版本核验状态和版本差异说明。
- 若新版教材已确认存在，但暂时找不到可检查的单元正文，不得回退旧版继续制作；应报告缺口并请求用户提供新版教材页。

## 来源优先级

按以下顺序选择来源：

1. 用户上传的教材页、目录、教师用书或学校正式材料。
2. 出版社、教育主管部门、国家教育平台等官方页面。
3. 学校、教研机构或教师公开的教学材料。
4. 两个以上能够相互印证的可信教学网站。
5. 搜索摘要、论坛、自媒体或聚合页只能作为线索，不得单独支撑教材事实。

同一层级内优先选择能看到正文、版本信息、页码或完整上下文的来源。

## 搜索步骤

1. 以当前日期和目标学年为基准，先查询教育部教学用书目录、出版社新版说明、官方数字教材和地方选用公告。
2. 组合查询：出版社 + 教材名称 + 最新/新版 + 适用学年 + 年级册次 + 单元编号。
3. 并行查询上一版教材，比较目录、单元标题、版式和核心内容，明确排除旧版。
4. 先确认最新教材目录和单元标题，再搜索词汇、句型和课文语境。
5. 打开关键页面正文；记录标题、发布日期、URL或文件位置、支持内容和证据级别。
6. 比较版本、拼写、单元编号和标题，标记冲突。
7. 对词表和句型至少使用一个主要来源；非官方来源尽量用两个独立来源交叉验证。

优先使用当前运行时的原生联网搜索。不可用时使用已安装且能够打开页面正文的搜索工具；只有已成功打开并检查页面正文的结果才能作为证据。只有 URL、无法检查正文、降级或失败的结果只能作为线索。

## 冲突与缺失

- 版本冲突：并列呈现候选版本、差异和来源，请用户选择。
- 新版已发布但正文不足：不要使用旧版词表补齐新版；请求用户提供新版教材页或等待可核验来源。
- 单元标题一致但词表不同：不要合并，先确认版本或让用户上传教材页。
- 只有搜索摘要：继续寻找可检查页面；找不到时说明证据不足。
- 网络不可用：请用户上传教材目录或相关页面，不要凭记忆补齐。
- 用户提供内容与网络不同：优先确认用户正在使用的实体教材，不暗中替换。

## 内容与版权边界

- 只提取完成学习资料所必需的词汇、短语、句型和有限语境。
- 不默认抓取、保存或重现完整教材课文、整册扫描件和付费资料。
- 需要完整课文时，优先让用户上传其合法持有的页面，并把使用范围限制在当前任务。
- 不把用户上传的临时教材图片或网络参考图固化为 Skill 通用资产。
